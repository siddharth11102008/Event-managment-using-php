🎉 Event Management System

This project is a web-based event management system built with Core PHP, MySQL, HTML, and CSS.

Features:
- User registration and login
- Browse available event packages
- View package details and pricing
- Book event packages with preferred event date
- View booking history and booking status
- Submit feedback and ratings
- View event gallery

Admin Features:
- Admin login
- Add, edit, and delete event packages
- Manage gallery images
- View all bookings
- Update booking status
- View user feedback and ratings

Technologies Used:
- PHP (Core PHP with mysqli)
- MySQL
- HTML
- CSS
- XAMPP

Purpose:
This project was developed as a diploma computer engineering academic project to demonstrate CRUD operations, user authentication, package booking workflow, image uploads, feedback management, and database connectivity.
